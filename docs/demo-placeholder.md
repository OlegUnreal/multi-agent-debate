# Demo recording

This folder is reserved for a short screen recording of a live debate.

## What to record

1. Start the server:
   ```bash
   python -m debate.server
   ```
2. Open http://127.0.0.1:8000, type a topic, hit Start.
3. Show proposer, critic and judge bubbles appearing round by round, then the final verdict.
4. Keep it under 30 seconds.

## Tools

- Windows: Xbox Game Bar (`Win + G`) or OBS Studio.
- Convert to GIF with [ScreenToGif](https://www.screentogif.com/) or `ffmpeg`.

Save the final file as `docs/demo.gif` and it will render automatically below.
